# B.A.B.C Quotation Studio

A React and TypeScript quotation app built as a client-side Vite site.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production files are written to `dist/`. Vercel is configured to build the
site with `npm run build` and serve that directory.
